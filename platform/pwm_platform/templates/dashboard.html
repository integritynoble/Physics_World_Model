Spec Builder

Design any imaging system using natural language. Supports all 168 modalities — from CASSI and MRI to NeRF and electron microscopy. Two usage modes:

{# ── Mode 1: Simulation ── #}
Mode 1

Prompt → Spec → Simulate

Design a system from scratch using natural language, then run synthetic benchmark simulations.

1 Describe: “Design a CT scanner with 360 projections”
2 Refine: Adjust noise, mismatch, forward-model primitives
3 Simulate: Click Run Simulation for benchmark results
{# ── Mode 2: Dataset + Reconstruct ── #}
Mode 2

Dataset+Prompt → Spec → Reconstruct

Upload your own measurement data, describe it in natural language, build a matched spec, then reconstruct.

1 Upload: Click Upload Dataset (.npy, .mat, .h5, .npz)
2 Prompt: “This is MRI k-space data with 4x undersampling”
3 Refine: Correct mismatch parameters to match your system
4 Reconstruct: Click Reconstruct from Dataset
