{# ══ Tab 1: Reconstruct ══ #}

What is Reconstruct?

Runs an inversion algorithm to recover an image x from its measurement y = H·x + noise. Choose a modality (CASSI, CT, MRI, SPC…) and a solver (GAP-TV, FBP, CS-MRI, RDLUF…). PWM runs the algorithm on benchmark data and reports PSNR / SSIM.

When to use:

  • Benchmarking a solver on standard PWM data
  • Reconstructing your own captured measurement (.npy / .mat)
  • Comparing classical vs. deep-learning performance

What is Mismatch?

Handles a gap between the calibrated forward model H̃ and the true one H caused by manufacturing tolerances, environment, or drift. PWM quantifies mismatch parameters, corrects H̃ → H, then reconstructs.

Common mismatch sources:

  • CASSI dispersion shift (lens misalignment)
  • CT source–detector distance error
  • MRI B₀ field inhomogeneity
  • Lensless PSF phase error from vibration

What is Design?

Generates a full imaging system architecture from a high-level specification. You provide the application, constraints (budget, size, SNR, resolution), and target. PWM outputs a system DAG: light source → optics → aperture → sensor → digitizer → reconstruction algorithm, with component specs and trade-off analysis.

When to use:

  • Starting a new instrument from scratch
  • Hardware–algorithm co-design optimization
  • Procurement spec writing
  • Comparing system architectures for a given target

Workflow

{# ══ Tab 4: Scientific Simulation ══ #}

What is Scientific Simulation?

Runs a physics-based forward model from first principles — governing equations, material parameters, boundary conditions — to generate synthetic observables. Unlike imaging reconstruction, the "measurement" is a physical field (pressure wave, temperature, gravitational strain, concentration) rather than a detector readout. PWM encodes the PDE / ODE / statistical model in spec.md and runs the simulation, then optionally inverts it.
