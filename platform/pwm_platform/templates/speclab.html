Design, compare, and simulate any imaging system using natural language. Supports all 168 modalities — from CACTI and MRI to NeRF and cryo-EM. Three unified workflows:

Mode 1

Prompt → Spec → Simulate

Design a system, compare across 168 modalities, or recommend the best system+solver for your task.

a System retrieval: “Which imaging system for NDT under $50k?”
b Solver recommendation: “Best algorithm for CACTI at <10s latency?”
c Co-design: “Design a single-shot system for retinal imaging”
→ Simulate: Run physics benchmark on recommended system

Mode 2

Data → Spec → Reconstruct

Upload your measurement data, build a matched spec, then reconstruct with the best solver.

1 Upload: .npy, .mat, .h5, .npz
2 Describe: “MRI k-space, 4x undersampling”
3 Reconstruct with best PWM solver
