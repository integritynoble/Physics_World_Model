# PWM Benchmark — Standard Dataset Forward Model References

Each modality's standard dataset is built from a **canonical reference** that defines:
- **Ground truth** x: what is being imaged
- **Forward model** y = H(x) + noise: how measurements are formed
- **Measurement matrix** H: structure of the sensing operator
- **Reconstruction**: how x is recovered from y
- **Source link**: verifiable DOI or URL

## Notes

1. **Forward model convention**: y = H(x) + noise, where x is the ground truth object/scene, H is the measurement operator, and y is the observed data.
2. **Measurement matrix structure**: For linear problems, H can be represented as a matrix; for nonlinear problems (SHG, CARS, NeRF, etc.), H is a nonlinear operator.
3. **Reconstruction**: Each reference contains the foundational physics for reconstruction. Standard reconstruction algorithms (FBP, FISTA, ADMM, GAP-TV, etc.) are applied per modality.
4. **All DOIs are resolvable** at `https://doi.org/{doi}`. ISBNs link to publisher pages.
5. **Alias modalities** (sd_cassi → cassi, spc_kronecker → cassi) share references with their parent modality.
