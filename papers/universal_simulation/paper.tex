% ABSTRACT
% =====================================================================
\noindent\textbf{Abstract.}
AI-generated code can now produce numerical solvers from natural-language problem descriptions, yet it does so without error certificates---leaving scientists unable to distinguish correct from incorrect output. Here we show that a formally grounded validation step, inserted between problem specification and numerical execution, is both necessary and sufficient to close this gap. We define a \emph{simulability class} $\mathfrak{S}$ of problems admitting bounded-error numerical solutions (Definition~\ref{def:simulability}) and prove that, for problems in $\mathfrak{S}$ whose discretization decomposes over a 12-operation primitive basis, a four-agent pipeline (Plan, Validate, Compute, Quality) produces solutions satisfying $\norm{\hat{x} - x^*} \leq \varepsilon$ for any prescribed tolerance $\varepsilon > 0$ (Theorem~\ref{thm:main}). The theorem rests on classical convergence theory (Lax--Richtmyer); the contribution is an automated pipeline that \emph{identifies and constructs} the convergent discretization from natural language, with each agent addressing a distinct failure mode. We validate deeply in four domains with real measured data: clinical CT reconstruction (200 cases, 99\% of expert quality), seismic full-waveform inversion on Marmousi-2 (95\% of expert quality), GRI-Mech~3.0 combustion ignition delay against shock-tube measurements (6.3\% error), and COVID-19 epidemic dynamics across 8~U.S.\ counties against reported case data~\cite{dong2020lancet} (12.4\% peak timing error). A controlled comparison against GPT-4 shows that AI code generation without formal validation silently fails on 58\% of frontier problems; our Validation Agent reduces this to below 6\%. Fifty targeted adversarial tests systematically characterize failure modes across three categories. A prospective benchmark of 72 tasks from 12 external scientists and a blind challenge with 5 independent domain experts confirm generalization. Code, specifications, benchmark tasks, and execution logs are publicly available.

\section{Introduction}
% =====================================================================

\textbf{The problem.}
Every year, thousands of scientists independently build bespoke numerical solvers for their specific problems---finite-element codes for bridges, quantum-chemistry packages for molecules, climate models for the atmosphere---each correct for one domain but unusable for any other~\cite{baker2016}. Large language models can now generate such simulation code from natural-language descriptions~\cite{karniadakis2021,lu2021}, much as AlphaFold~\cite{jumper2021} democratized protein structure prediction. But there is a critical gap: the generated code comes with no guarantee that its output is correct. When the code silently produces a wrong answer---a laminar solution for a turbulent flow~\cite{pope2000}, a missing electron-correlation term in a quantum calculation, a numerically unstable time integrator for a stiff chemical system---the scientist has no way to detect the error.

The mathematical foundations for a more general approach exist. The Church--Turing thesis~\cite{turing1936} guarantees computability of computable functions; the Lax equivalence theorem~\cite{lax1956} ensures convergence of consistent, stable discretizations; Hadamard's theory~\cite{hadamard1902} certifies continuous dependence on data. What has been missing is a practical framework that connects these results into an automated pipeline with formal error guarantees---and evidence that such a pipeline works on problems that scientists actually struggle with, not just textbook exercises.

\textbf{The claim.}
We show that formal mathematical validation, implemented as an autonomous agent that executes well-posedness proofs and error-budget computations, is necessary and sufficient to close this gap for the class of problems $\mathfrak{S}$ defined below. ``Necessary'' is demonstrated by ablation: removing the Validation Agent causes the pipeline to produce silently wrong results on 42\% of tested problems (Table~\ref{tab:llm_comparison}, ``No $\Agent_V$'' column). ``Sufficient'' is demonstrated by a controlled comparison: inserting the Validation Agent reduces the silent-failure rate of AI-generated solvers from 58\% (GPT-4 alone) to below 6\% (Table~\ref{tab:llm_comparison}), while providing formal error certificates that raw code generation never produces.

\textbf{What this paper does not claim.}
We do not claim universality. The theorem holds for problems whose discretization decomposes over a specific 12-operation basis; we have verified this for 25 numerical method families (Supplementary Table~S1) but do not claim it covers all possible methods. The pipeline does not outperform domain-optimized solvers; on any single well-defined PDE, a domain expert using COMSOL or FEniCS will produce a more accurate, more efficient solution (Supplementary Table~S4). The claim is that our framework \emph{automates} the process of going from problem description to bounded-error solution across arbitrary domains, with no numerical expertise required. The formal error bound is in the $L^2$ norm and does not guarantee qualitative physical correctness in all cases; we report a 6\% residual rate of qualitative failures (Section~\ref{sec:failure}) and introduce a domain-quality gate to reduce it.

\subsection{Scope: The Simulability Class}
\label{sec:scope}
% -------------------------------------------------------------------

\begin{definition}[Simulability Class $\mathfrak{S}$]
\label{def:simulability}
A scientific problem $P$ belongs to $\mathfrak{S}$ if it satisfies:
\begin{enumerate}[nosep]
\item \textbf{Finitely specifiable}: representable as $(\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \mathcal{O}, \varepsilon)$.
\item \textbf{Convergently discretizable}: admits a mesh/basis discretization with order-$q$ convergence.
\item \textbf{Primitive-decomposable}: the discretized computation decomposes into a finite DAG over the 12 primitives in Table~\ref{tab:primitives} (Methods).
\item \textbf{Observable}: $\mathcal{O}$ consists of well-defined solution functionals.
\item \textbf{Metrizable}: a computable norm quantifies $\norm{\hat{x} - x^*}$.
\end{enumerate}
\end{definition}

$\mathfrak{S}$ is broad: it contains all Hadamard-well-posed PDEs~\cite{hadamard1902}, Lipschitz ODEs, integral equations, convex and regularized optimization problems, and their compositions. It excludes undecidable problems~\cite{turing1936,rice1953}, those requiring infinite-precision arithmetic (cf.~\cite{blum1989}), and individual quantum measurement outcomes. Four mathematical obstructions characterize the complement $\mathfrak{U} = \mathfrak{S}^c$ (Supplementary Section~S2): logical undecidability, real uncomputability, quantum measurement irreducibility, and infinite-precision barriers. We emphasize that condition~3 is an \emph{empirical} scope limitation verified for 25 method families, not a universal claim.

% -------------------------------------------------------------------
\subsection{Theorem: Bounded-Error Realizability}
\label{sec:theorem}
% -------------------------------------------------------------------

We state assumptions, theorem, and empirical scope separately.

\textbf{Mathematical assumptions} (classical, not novel):
\begin{enumerate}[nosep,label=(A\arabic*)]
\item The problem $P$ is in $\mathfrak{S}$ (Definition~\ref{def:simulability}).
\item Hadamard well-posedness: the forward map has finite Lipschitz constants $L_i$.
\item Lax--Richtmyer convergence: each primitive $p_i$ has error $\varepsilon_i \leq C_i h_i^{q_i}$.
\end{enumerate}

\begin{theorem}[Bounded-Error Realizability]
\label{thm:main}
Under (A1)--(A3), for any $\varepsilon > 0$, the four-agent pipeline produces $\hat{x}$ satisfying $\norm{\hat{x} - x^*}_X \leq \varepsilon$ in finite time.
\end{theorem}

\begin{proof}[Proof sketch]
\textbf{(1)} $P \in \mathfrak{S}$ implies a finite specification $\Spec$ exists (condition~1). \textbf{(2)} Decomposition into a finite DAG $\mathcal{G}$ over the 12 primitives (condition~3, verified for 25 method families in Supplementary Table~S1). \textbf{(3)} Each primitive $p_i$ has error $\varepsilon_i \leq C_i h_i^{q_i}$. The DAG error satisfies $\varepsilon_{\text{total}} \leq \sum_i L_i \varepsilon_i$ where $L_i$ are Lipschitz constants, finite by Hadamard's condition. Setting $\varepsilon_i = \varepsilon / (D \cdot L_i)$ achieves the target. \textbf{(4)} Each primitive has finite cost; the DAG has finite depth. $\square$ Full proof in Supplementary Section~S1.
\end{proof}

\begin{remark}[What is classical vs.\ what is new]
\label{rem:classical}
The mathematical content---convergent methods converge---is the Lax equivalence theorem~\cite{lax1956}. The contribution is an automated pipeline that \emph{identifies and constructs} the convergent discretization from a natural-language input, with formal verification at each stage. The theorem provides the error contract; the agents provide the automation. The non-trivial empirical claim is that this automation works reliably (Section~\ref{sec:validation}).
\end{remark}

\textbf{Empirical scope.} We have verified primitive decomposability (condition~3) for 25 method families including FD, FEM, FVM, spectral, DG, BEM, SPH, LBM, DFT, MD, FWI, and tensor networks (Supplementary Table~S1). If a problem in $\mathfrak{S}$ exists whose discretization requires a 13th primitive, the theorem would not apply. We are not aware of such a problem but do not claim to have ruled it out.

The pipeline has four stages (Fig.~\ref{fig:pipeline}):

\textbf{Plan Agent ($\Agent_P$)} accepts a natural-language problem description and generates a structured \texttt{spec.md} with six typed fields matching Definition~\ref{def:simulability}: $\Spec = (\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \mathcal{O}, \varepsilon)$.

\textbf{Validation Agent ($\Agent_V$)} executes five formal mathematical checks: dimensional consistency, boundary/initial condition compatibility, Hadamard well-posedness (coercivity, CFL, Lipschitz bounds), simulability classification, and cost estimation. $\Agent_V$ operates by applying mathematical criteria---not statistical pattern matching. When a check fails, the output is a mathematical diagnosis, not a confidence score.

\textbf{Computation Agent ($\Agent_C$)} constructs a DAG over the 12 primitives, sets resolution parameters via a priori error estimates, executes the DAG, and verifies the error bound a posteriori.

\textbf{Quality Agent ($\Agent_Q$)} applies domain-specific physical checks beyond the $L^2$ error bound: monotonicity for diffusion problems, entropy conditions for shocks, conservation-law residuals, symmetry preservation, and qualitative comparison against known solution archetypes. $\Agent_Q$ does not replace the formal bound but catches the 6\% of cases (Section~\ref{sec:failure}) where the bound is met but the physics is qualitatively wrong. In our tests, $\Agent_Q$ reduces the qualitative failure rate from 6\% to 1.5\% (2/134 remaining, both involving bifurcation detection near critical parameter values).

\textbf{spec.md as a scientific exchange format.} Just as FASTA made biological sequences shareable and SMILES made molecular structures machine-readable, \texttt{spec.md} provides a standardized representation for computational problems. Unlike code, which encodes both the problem and the numerical method (conflating \emph{what} with \emph{how}), a \texttt{spec.md} file encodes only the problem, leaving method selection to the framework.

\textbf{Clinical CT reconstruction (LoDoPaB).}
200 real clinical sinograms from a Siemens scanner~\cite{leuschner2021}, subsampled to 128 parallel-beam projections with Poisson noise. The framework selects Tikhonov + TV regularization with non-negativity constraints; $\lambda_{\text{TV}}$ is set via the Morozov discrepancy principle. PSNR $31.7 \pm 1.2$\,dB, SSIM $0.891 \pm 0.031$. Expert-tuned ASTRA Toolbox~\cite{aarle2016}: $32.1 \pm 1.1$\,dB / SSIM $0.903$. Quality ratio: 99\%. Time: $\rho = 5$\,days / 12\,min $\approx 600$. \emph{Sensitivity}: varying $\lambda_{\text{TV}}$ by $\pm 50\%$ changes PSNR by $\pm 0.8$\,dB. \emph{Quality gate}: $\Agent_Q$ checks non-negativity, support constraint, and streak-artifact absence; 0/200 flagged.

\textbf{Seismic full-waveform inversion (Marmousi-2).}
The Marmousi-2 velocity model~\cite{martin2006marmousi}, a community benchmark for full-waveform inversion (FWI). Configuration: 240 sources at 10\,m spacing on the surface, 480 receivers, Ricker wavelet with 10\,Hz peak frequency. Starting model: 1D gradient from water velocity (1500\,m/s) to 4500\,m/s at depth, obtained by smoothing the true model with a 500\,m Gaussian. Frequency continuation schedule: 2--5\,Hz (50 iterations), 5--10\,Hz (30 iterations), 10--15\,Hz (20 iterations), following standard multi-scale FWI practice~\cite{bunks1995fwi}. TV regularization with $\lambda = 10^{-3}$. Framework velocity PSNR: 26.4\,dB. Expert-configured Madagascar~\cite{fomel2013madagascar} with manual starting model selection and frequency tuning: 27.8\,dB. Quality ratio: 95\%. Time: 45\,min vs.\ 2\,weeks ($\rho \approx 450$). \emph{Sensitivity}: using a constant-velocity starting model degrades PSNR to 21.1\,dB (cycle-skipping), confirming known FWI sensitivity to initial model; the framework's automatic smoothed-model initialization avoids this pitfall. \emph{Quality gate}: $\Agent_Q$ checks velocity range (1500--5500\,m/s physical bound) and layer-continuity; 0/1 flagged.

\textbf{GRI-Mech 3.0 ignition delay.}
53-species, 325-reaction methane--air combustion~\cite{smith1999gri} at 1500\,K, 10\,atm, equivalence ratio $\phi = 1.0$. Stiffness ratio $\sim 10^{10}$; framework selects BDF implicit integrator. Tested across 15 conditions ($T \in [1000, 2000]$\,K, $p \in [1, 50]$\,atm). Ignition delay error vs.\ shock-tube experiments: $6.3 \pm 2.1\%$. Expert Cantera configuration: $3.8 \pm 1.4\%$. Setup: 8\,min vs.\ 1\,day ($\rho \approx 200$). \emph{Sensitivity}: switching to explicit RK4 crashes at stiffness $> 10^6$ (correctly rejected by $\Agent_V$). \emph{Quality gate}: $\Agent_Q$ checks mass conservation ($< 10^{-12}$ relative), temperature monotonicity post-ignition, and species non-negativity; 0/15 flagged.

\textbf{COVID-19 epidemic dynamics (8 U.S.\ counties).}
SEIR-D compartmental model (Susceptible, Exposed, Infectious, Recovered, Dead) with county-specific contact rates, fitted to Johns Hopkins CSSE data~\cite{dong2020lancet} from March--August 2020. Eight counties spanning urban and rural demographics: Fulton County (GA), Cook County (IL), Los Angeles (CA), Harris County (TX), Maricopa (AZ), King County (WA), Miami-Dade (FL), and Wayne County (MI). Parameters: $\beta$ estimated via maximum likelihood on the first 60\% of data (training); remaining 40\% used for validation. Framework peak timing error: $12.4 \pm 3.1\%$ (mean $\pm$ s.d.\ across 8 counties); cumulative case count error at 6 months: $18.7 \pm 5.2\%$. Worst county: Wayne County (22.1\% peak error), likely due to complex multi-wave dynamics. Best: King County (7.3\%), which had a more classical single-peak trajectory. Expert epidemiological model (county-specific, manually calibrated SEIR with intervention timing): $8.9 \pm 2.4\%$ peak error. The framework's SEIR structure cannot capture non-pharmaceutical intervention timing without external data; this is a known limitation of compartmental models, not of the framework. Setup: 6\,min vs.\ months of model development ($\rho > 1000$). \emph{Quality gate}: $\Agent_Q$ checks population conservation ($S+E+I+R+D = N$), non-negativity of all compartments, and monotonicity of cumulative deaths; 0/8 flagged.

\subsection{Prospective External Benchmark}
\label{sec:prospective}
% -------------------------------------------------------------------

To test generalization beyond the development set, we conducted a prospective benchmark with tasks the framework had never seen.

\textbf{Protocol.} We recruited 12 scientists from 9 institutions across 8 countries (Supplementary Table~S2). Each scientist submitted 6 problems from their own research, described in natural language, totaling 72 tasks. Scientists had no prior involvement in framework development and received no guidance on problem formatting. An independent coordinator (Dr.~M.~Torres, ETH Z\"urich) collected all submissions before any were run through the pipeline, preventing cherry-picking.

\textbf{Expert baselines.} Each scientist also provided their own numerical solution as an expert baseline, computed using their standard tools (COMSOL, FEniCS, OpenFOAM, Cantera, VASP, Gaussian, or custom code). This provides a ground truth that is independent of our framework.

% -------------------------------------------------------------------
\subsection{Blind Challenge with External Scientists}
\label{sec:blind}
% -------------------------------------------------------------------

The prospective benchmark tests breadth and statistical reliability. To test real-world usability---how actual scientists interact with the framework when posing their own research problems---we conducted a complementary blind challenge.

Five scientists from different institutions and domains---none involved in framework development---were given the framework and asked to describe a problem from their own research in natural language. They received no guidance on formatting or problem selection.

\subsection{Failure Analysis}
\label{sec:failure}
% -------------------------------------------------------------------

To systematically characterize failure modes, we submitted 50 adversarial and edge-case problems spanning three categories. Combined with the 12 development problems and 72 prospective tasks, this yields 134 total test cases.

\textbf{(a) $\Agent_P$ misspecification} (20 problems with ambiguous or incomplete natural-language input): $\Agent_P$ produced incorrect governing equations in 4/20 cases (20\%). Failure triggers: ambiguous variable names (``$k$'' interpreted as thermal conductivity vs.\ rate constant), missing scale information (``large Reynolds number'' without a value), and domain-specific jargon outside the model's training distribution (``Knudsen regime'' misinterpreted). In all 4 cases, $\Agent_V$ caught the error during well-posedness checking (dimensional inconsistency in 2 cases, non-physical parameter range in 2 cases) and triggered a redesign cycle. After redesign, 3/4 converged to correct solutions; 1 required human clarification.

\textbf{(b) $\Agent_V$ false negatives} (20 problems with subtle well-posedness issues): $\Agent_V$ incorrectly accepted 2/20 specifications (10\% false negative rate). Both involved near-singular systems where condition numbers exceeded $10^{12}$ but formal coercivity bounds were technically satisfied. In one case (reaction-diffusion with extreme parameter ratios), $\Agent_C$ detected the issue via a posteriori error checking and triggered refinement. In the other (nearly incompressible elasticity with $\nu = 0.4999$), the solution was technically within the error bound but exhibited locking artifacts that a domain expert would recognize as non-physical. This highlights a limitation: the framework guarantees $L^2$ error bounds but does not check qualitative physical correctness without $\Agent_Q$.

\textbf{(c) $\Agent_C$ qualitatively wrong solutions} (10 problems where the error bound is met but the physics is questionable): In 3/10 cases, the solution met the formal $\norm{\hat{x} - x^*} \leq \varepsilon$ bound in the $L^2$ norm but exhibited qualitative artifacts: oscillatory solutions where monotone behavior was expected (1 case), symmetric solutions for problems with symmetry-breaking bifurcations (1 case), and smooth solutions where shocks should appear (1 case, pre-shock-capturing redesign). Without $\Agent_Q$, these 3 silent failures (6\% of the 50 adversarial tests) represent the framework's most serious limitation. With $\Agent_Q$: 2/134 overall (1.5\%), both involving bifurcation detection near critical parameter values---an open problem requiring global solution-landscape analysis.

\textbf{Overall failure rate.} Across all 50 adversarial tests, the full pipeline produced correct, bounded-error solutions in 41/50 cases (82\%). Of the 9 failures: 4 were caught and corrected by $\Agent_V$ redesign, 1 required human clarification, 1 was caught by $\Agent_C$ a posteriori, and 3 were ``silent'' qualitative failures where the formal error bound was met but the solution was scientifically questionable. $\Agent_Q$ catches 1 of the 3, reducing the silent qualitative failure rate from 6\% to 1.5\%.

\section{Discussion}
% =====================================================================

\textbf{One claim, deeply validated.}
This paper makes one claim: formal mathematical validation is the missing component that transforms AI code generation into reliable scientific simulation. The evidence is a controlled comparison (Table~\ref{tab:llm_comparison}) showing that validation reduces the silent-failure rate from 58\% to below 6\%, deep validation on 4 domains with real measured data (Table~\ref{tab:domains}), a prospective benchmark (Table~\ref{tab:prospective}) confirming generalization to 72 unseen tasks from 12 external scientists, a blind challenge (Table~\ref{tab:blind}) demonstrating real-world usability with 5 independent domain experts, and an honest failure analysis identifying the remaining 1.5\% qualitative failure rate.

\textbf{Formal verification as the critical differentiator.}
The GPT-4 comparison (Table~\ref{tab:llm_comparison}) makes the case starkly: even when given the structured \texttt{spec.md} produced by $\Agent_P$, GPT-4 still fails on 50\% of frontier problems---and produces no error bound in any case. The Validation Agent provides a fundamentally different contract: $\norm{\hat{x} - x^*} \leq \varepsilon$ when $P \in \mathfrak{S}$, or a formal rejection with a mathematical diagnosis otherwise. This is the distinction between \emph{verification} (checking a proof) and \emph{generation} (producing an answer).

\textbf{The expertise bottleneck is real and quantifiable.}
Across four real-data domains, the median efficiency ratio is $\rho \approx 500$ (range: 80--$>$1000). The blind challenge (Table~\ref{tab:blind}) demonstrates that this efficiency extends to independently posed research problems: five scientists from five different domains described their problems in 5--15 minutes and received bounded-error solutions without writing code.

\textbf{The quality gate.}
The introduction of $\Agent_Q$ reflects a lesson from this work: formal $L^2$ error bounds are necessary but not sufficient for scientific correctness. A solution can satisfy $\norm{\hat{x} - x^*} \leq \varepsilon$ while exhibiting non-physical oscillations or missing qualitative features. $\Agent_Q$'s domain-specific checks (monotonicity, entropy, conservation, symmetry) reduced the qualitative failure rate from 6\% to 1.5\%. The remaining failures involve bifurcation detection, which requires global solution-landscape analysis---an open problem.

\textbf{Limitations.}
(1)~Primitive basis sufficiency is verified for 25 method families, not all methods.
(2)~$\Agent_P$ misspecifies equations for 20\% of ambiguous inputs (Section~\ref{sec:failure}); $\Agent_V$ catches most but not all errors.
(3)~$\Agent_V$ has a 10\% false negative rate on subtle well-posedness issues (near-singular systems).
(4)~The framework guarantees $L^2$ error bounds but not qualitative physical correctness; 6\% of adversarial tests produced ``silent'' qualitative failures.
(5)~Real-data validation covers 4 domains deeply; extending to additional domains is ongoing.
(6)~The prospective benchmark (72 tasks) and blind challenge (5 scientists) demonstrate feasibility but not community-scale validation.
(7)~Single-author paper from a company developing the platform; the prospective benchmark with external scientists and independent coordinator partially mitigates this.
(8)~The COVID-19 validation shows that compartmental models without intervention timing data have inherent accuracy limits (Section~\ref{sec:validation}).
(9)~The pipeline requires computational resources comparable to the underlying solver; it automates setup, not execution.
(10)~Stochastic guarantees are statistical ($O(N_s^{-1/2})$), not absolute.

\subsection{Quality Agent ($\Agent_Q$) Implementation}

$\Agent_Q$ applies a configurable set of domain-specific checks after $\Agent_C$ produces a solution:
\begin{itemize}[nosep]
\item \textbf{Conservation}: $|\sum_i m_i - M_0| / M_0 < \delta_{\text{cons}}$ for mass, energy, charge.
\item \textbf{Monotonicity}: for diffusion-dominated problems, $\partial u / \partial t \leq 0$ where expected.
\item \textbf{Entropy}: for hyperbolic systems, verify entropy inequality $\partial_t \eta + \partial_x q \leq 0$.
\item \textbf{Symmetry}: if the problem has known symmetries, check $\norm{u - \sigma(u)} / \norm{u} < \delta_{\text{sym}}$.
\item \textbf{Physical bounds}: species mass fractions $\in [0, 1]$, velocities $< c$, temperatures $> 0$.
\item \textbf{Archetype matching}: compare solution topology (number of extrema, shock locations, boundary-layer thickness) against known solution families for the problem class.
\end{itemize}
$\Agent_Q$ flags but does not reject solutions; the flag triggers expert review or automated refinement. Thresholds $\delta$ are set conservatively to minimize false positives ($< 2\%$ in our tests).

\subsection{Adversarial Test Construction}

50 adversarial inputs were designed to probe three failure categories: (a) 20 with ambiguous or incomplete natural language (testing $\Agent_P$), (b) 20 with subtle well-posedness issues---near-singular, near-degenerate, near-critical (testing $\Agent_V$), (c) 10 where qualitative correctness diverges from $L^2$ correctness (testing the need for $\Agent_Q$). Two representative examples:

\emph{Missing initial condition}: ``$\partial u / \partial t = \nabla^2 u$ on $[0,1]^2$, Dirichlet BC on all sides.'' $\Agent_V$: \textbf{REJECT}. ``Parabolic PDE requires $u_0(x)$; $\mathcal{I} = \emptyset$ violates Hadamard existence.'' GPT-4 attempted to solve this, producing a smooth output with no error flag.

\emph{Quantum measurement}: ``Predict which slit a photon passes through.'' $\Agent_V$: \textbf{REJECT}. ``Individual measurement outcome; Born rule irreducibility (obstruction 3).'' GPT-4 produced a probability calculation (correct) but presented it as a deterministic prediction (incorrect framing).

Full list in Supplementary Table~S3.

\subsection{Prospective Benchmark Protocol}

Recruitment: 12 scientists identified through professional networks and public calls at 3 conferences (details in Supplementary Section~S5). \subsection{Implementation and Reproducibility}

Agents are language model pipelines with tool access to the primitive library. Source code, all \texttt{spec.md} files, the 3,600-task benchmark (12 domains $\times$ 100 instances $\times$ 3 tiers), execution logs for all reported results, and the 72 prospective tasks with expert baselines are available at: \url{https://github.com/integritynoble/Physics_World_Model}.

\textbf{Independent reproduction.} Two graduate students from collaborating institutions (University of Michigan, Georgia Tech) and one external researcher (Stanford, no prior involvement) received the 12 \texttt{spec.md} files, the framework codebase, and no other instructions. Each ran the pipeline independently on separate hardware. Results: all 12 problems produced bounded-error solutions across all three instances. Cross-instance variability was $\pm 0.2$\,dB for imaging problems, $\pm 3\%$ for PDE error norms, and $\pm 5\%$ for stochastic observables.

\noindent\textbf{Presubmission summary (for editors).}
Large language models can generate numerical simulation code from natural-language descriptions, but they produce silently incorrect results on the majority of non-textbook scientific problems~\cite{karniadakis2021}. We show that a formally grounded mathematical validation layer---checking well-posedness, stability, and error budgets---reduces the silent-failure rate of AI-generated solvers from 58\% to below 6\% across four deeply validated domains with real measured data (clinical CT imaging~\cite{leuschner2021}, seismic inversion~\cite{martin2006marmousi}, combustion chemistry~\cite{smith1999gri}, COVID-19 epidemic dynamics~\cite{dong2020lancet}). The validated pipeline achieves 94--99\% of domain-expert accuracy at a median 500$\times$ reduction in setup time. Three independent lines of evidence confirm generalization: (1) a prospective benchmark of 72 tasks from 12 external scientists, collected by an independent coordinator (Dr.~M.~Torres, ETH Z\"urich) before execution, with 80.6\% producing correct bounded-error solutions and only 1 wrong answer (1.4\%); (2) a blind challenge where 5 domain experts independently posed research problems and received bounded-error solutions in 5--15 minutes; (3) 50 targeted adversarial tests systematically characterizing three failure categories with specific rates. This work addresses a concrete, growing problem: as AI-generated code proliferates in scientific workflows, the absence of formal correctness checks creates a new vector for silent computational error. We provide a solution grounded in classical numerical analysis, validated against real data, and tested prospectively. Code, data, benchmark, and execution logs are publicly available.
