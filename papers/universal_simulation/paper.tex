\noindent\textbf{Summary.}
Scientists in every discipline build bespoke computational solvers---finite-element codes for bridges, quantum-chemistry packages for molecules, epidemiological simulators for disease spread. Each solver works for one class of problems but cannot be reused for another, creating an expertise bottleneck that limits who can simulate what. Here we ask: is there a single framework that can simulate \emph{any} problem within a rigorously defined class, with guaranteed error bounds? We identify such a class---the \emph{simulability class} $\mathfrak{S}$, comprising all finitely specifiable, numerically approximable problems with explicit observables---and prove its sharp boundary against four fundamental mathematical obstructions. We show that structured specifications (\texttt{spec.md} files), validated and executed by a three-agent pipeline over 12 computational primitives, achieve bounded-error simulation for every problem in $\mathfrak{S}$. We validate this across 12 scientific domains including a real clinical CT dataset, demonstrate through ablation that each pipeline component is necessary, and show that every problem in $\mathfrak{S}$ is automatically benchmarkable---enabling open competition across all of simulable science.

\vspace{6pt}
\noindent\textbf{Keywords:} scientific event horizon, simulability class, specification-driven simulation, computational primitives, agent pipeline

\section{Introduction}
% ========================================================================

Every year, thousands of scientists independently build numerical solvers. A structural engineer writes finite-element code; a quantum chemist implements configuration-interaction routines; a climate modeler couples ocean and atmosphere modules. Each solver is correct for its domain but cannot be reused for any other. This \emph{expertise bottleneck}---the requirement that every new problem demands a new, hand-crafted computational pipeline---limits who can simulate what and creates a reproducibility crisis across computational science~\cite{baker2016}.

The mathematical foundations for unification exist. The Church--Turing thesis~\cite{turing1936} guarantees that computable functions can be evaluated by a universal machine. The Lax equivalence theorem~\cite{lax1956} ensures that consistent, stable discretizations converge. Hadamard's well-posedness theory~\cite{hadamard1902} certifies continuous dependence on data. What has been missing is a framework that connects these classical results into a practical, automated pipeline.

Here we present such a framework. Our contributions are:

\begin{enumerate}[nosep]
\item \textbf{The scientific event horizon}: a sharp boundary separating a rigorously defined simulability class $\mathfrak{S}$ from four fundamental obstructions that defeat \emph{any} computational system (Proposition~\ref{prop:boundary}).
\item \textbf{Bounded-error realizability}: for any problem in $\mathfrak{S}$ and any tolerance $\varepsilon > 0$, the framework produces $\hat{x}$ with $\norm{\hat{x} - x^*} \leq \varepsilon$ in finite time (Theorem~\ref{thm:main}).
\item \textbf{Specification-driven pipeline}: structured specifications (\texttt{spec.md}), not code, are the unit of scientific input. Three agents---Plan, Validation, Computation---transform specifications into solutions.
\item \textbf{Empirical validation}: 12 domains, one real clinical dataset, and ablation studies proving each pipeline component is necessary.
\end{enumerate}

This extends our previous result on imaging-specific primitives~\cite{paperI} to the broader simulability class.

\subsection{The Simulability Class and Its Boundary}
\label{sec:boundary}
% ------------------------------------------------------------------------

We begin by defining exactly what the framework covers and what it excludes.

\begin{definition}[Simulability Class $\mathfrak{S}$]
\label{def:simulability}
A scientific problem $P$ belongs to the simulability class $\mathfrak{S}$ if and only if it satisfies all six conditions:
\begin{enumerate}[nosep]
\item \textbf{Finitely specifiable}: $P$ can be represented as a finite tuple $(\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \Obs, \varepsilon)$ where $\Domain \subseteq \R^d$ is the spatial domain, $\mathcal{E}$ are governing equations, $\mathcal{B}$ are boundary conditions, $\mathcal{I}$ are initial conditions, $\Obs$ is a set of observable quantities, and $\varepsilon > 0$ is the target tolerance.
\item \textbf{Numerically approximable}: there exists a convergent discretization of $\mathcal{E}$ on $\Domain$.
\item \textbf{Expressible over the primitive basis}: the discretized system decomposes into a finite directed acyclic graph (DAG) over 12 computational primitives (Table~\ref{tab:primitives}).
\item \textbf{Explicit observables}: $\Obs$ consists of well-defined functionals of the solution.
\item \textbf{Explicit error metric}: a computable norm or metric quantifies the distance between computed and true solutions.
\item \textbf{Bounded resource assumptions}: the required computational resources (time, memory) are finite for any fixed $\varepsilon > 0$.
\end{enumerate}
\end{definition}

This class is broad---it contains all well-posed PDEs, ODEs, integral equations, optimization problems, stochastic systems, and their compositions across physics, chemistry, biology, engineering, and applied mathematics. But it is not everything.

\begin{proposition}[The Scientific Event Horizon]
\label{prop:boundary}
The complement $\mathfrak{U} = \mathfrak{S}^c$ is characterized by four fundamental obstructions, each of which defeats any conceivable computational system---classical, quantum, or hypothetical:
\begin{enumerate}[nosep]
\item \textbf{Logical undecidability} (G\"odel--Turing): problems reducible to the halting problem or Hilbert's tenth problem over $\Z$.
\item \textbf{Real uncomputability} (Blum--Shub--Smale~\cite{blum1989}): decision problems over $\R$ requiring infinite-precision predicates.
\item \textbf{Quantum measurement irreducibility}: individual measurement outcomes governed by the Born rule (only distributions are computable).
\item \textbf{Infinite-precision barriers}: solutions depending on non-computable real numbers (Chaitin's $\Omega$~\cite{rice1953}).
\end{enumerate}
\end{proposition}

The boundary $\partial\mathfrak{S}$ is what we call the \emph{scientific event horizon}.
Unlike engineering limitations that yield to better hardware or algorithms, these four obstructions are theorems of mathematics: the halting problem will never be solved, the Born rule will never be circumvented, and Chaitin's $\Omega$ will never be computed.
The event horizon is therefore a \emph{fundamental constant of computational epistemology}---it delimits what any intelligence, human or artificial, can know through simulation, in the same way that the speed of light delimits what can be observed through causal contact.
This is not a feature of our framework; it is a discovery about the structure of scientific knowledge itself.
Our framework's contribution is to reach this boundary constructively from below.
Table~\ref{tab:boundary} catalogs representative problems at each stratum.

\textbf{Chaos and turbulence.}
A natural objection is that many real-world problems---turbulence, climate, financial markets---are chaotic. These are in $\mathfrak{S}$ when the observables are statistical: mean velocity profiles, energy spectra, Lyapunov exponents, and ensemble statistics are all computable via ergodic averaging~\cite{pope2000}. Pointwise trajectories at long times are in $\mathfrak{S}_{\text{exp}}$ with impractical cost. The Validation Agent automatically detects chaotic sensitivity and recommends statistical observables.

\subsection{Bounded-Error Realizability}
\label{sec:theorem}
% ------------------------------------------------------------------------

The central result is that $\mathfrak{S}$ is exactly the class reachable by our framework.

\begin{theorem}[Bounded-Error Realizability]
\label{thm:main}
For any problem $P \in \mathfrak{S}$ with specification $\Spec = (\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \Obs, \varepsilon)$ and any $\varepsilon > 0$, the three-agent pipeline over the 12-primitive basis produces $\hat{x}$ satisfying
\[
\norm{\hat{x} - x^*}_X \leq \varepsilon
\]
in finite time $T_{\textup{comp}} < \infty$, where $x^*$ is the true solution.
\end{theorem}

\begin{proof}[Proof sketch (full proof in Methods)]
\textbf{Step 1.} $P \in \mathfrak{S}$ implies a faithful specification exists (Definition~\ref{def:simulability}, condition 1).
\textbf{Step 2.} Condition 3 guarantees decomposition into a finite DAG $\mathcal{G}$ over the 12 primitives.
\textbf{Step 3.} Each primitive $p_i$ has error $\varepsilon_i \leq C_i h_i^{q_i}$ parameterized by a resolution variable. The DAG error satisfies $\varepsilon_{\text{total}} \leq \sum_{i \in \text{path}} L_i \varepsilon_i$ where $L_i$ are Lipschitz constants, finite by Hadamard's condition. Setting $\varepsilon_i = \varepsilon / (D \cdot L_i)$ where $D$ is the DAG depth achieves the target.
\textbf{Step 4.} Each primitive has finite cost; the DAG has finite depth. $\square$
\end{proof}

Theorem~\ref{thm:main} is scoped to $\mathfrak{S}$---it makes no claim about problems outside this class. The framework is explicitly falsifiable: for any submitted problem, either $\Agent_V$ classifies it as $P \in \mathfrak{U}$ with a formal proof (reduction to halting, BSS certificate, or quantum irreducibility argument), or the framework produces $\hat{x}$ with $\norm{\hat{x} - x^*} \leq \varepsilon$. A failure in either case is diagnosable and correctable.

The 12 primitives (Table~\ref{tab:primitives}) are both sufficient for $\mathfrak{S}$ and minimal: removing any one breaks coverage (see Methods for witness construction).

\subsection{The Specification-Centered Pipeline}
\label{sec:pipeline}
% ------------------------------------------------------------------------

The framework's central insight is that the unit of scientific input should be a \emph{specification}, not code. A \texttt{spec.md} file is a structured document that defines a scientific problem in a format readable by both humans and agents:

\begin{quote}\small\ttfamily
\# Specification: 2D Heat Conduction\\
domain: [0,1]$\times$[0,1]\\
equations: du/dt = alpha * (d\^{}2u/dx\^{}2 + d\^{}2u/dy\^{}2)\\
parameters: alpha = 0.01\\
boundary: u(0,y) = u(1,y) = u(x,0) = 0; u(x,1) = sin(pi*x)\\
initial: u(x,y,0) = 0\\
observables: u(x,y,T) at T = 1.0\\
tolerance: 1e-4\\
\end{quote}

\begin{quote}\small\ttfamily
\# Specification: CT Reconstruction\\
domain: 128$\times$128 image grid\\
equations: y = Radon(x) + noise, noise $\sim$ Poisson\\
parameters: n\_angles = 180, geometry = parallel\_beam\\
boundary: non-negativity constraint, x $\geq$ 0\\
initial: N/A (inverse problem)\\
observables: reconstructed image x\_hat\\
tolerance: PSNR $\geq$ 30 dB\\
\end{quote}

\begin{quote}\small\ttfamily
\# Specification: SIR Epidemic Model\\
domain: t in [0, 200] days\\
equations: dS/dt = -beta*S*I/N; dI/dt = beta*S*I/N - gamma*I; dR/dt = gamma*I\\
parameters: beta = 0.3, gamma = 0.1, N = 1e6, I(0) = 10\\
boundary: S + I + R = N (conservation)\\
initial: S(0) = N - I(0), I(0) = 10, R(0) = 0\\
observables: I(t) peak timing, S(200)\\
tolerance: 1e-3\\
\end{quote}

These three specifications span PDEs, inverse problems, and ODE systems---yet all follow the same six-field format from Definition~\ref{def:simulability}. The key observation is that \emph{writing a spec.md requires domain knowledge but not numerical expertise}. A biologist can specify an SIR model; the framework handles the discretization, solver selection, and error control.

\textbf{Plan Agent ($\Agent_P$).}
Parses \texttt{spec.md} into a typed specification $\Spec = (\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \Obs, \varepsilon)$, classifies the problem type (PDE, ODE, inverse, stochastic), selects an appropriate numerical strategy, and identifies required primitives.

\textbf{Validation Agent ($\Agent_V$).}
Performs five formal checks: (1) dimensional consistency; (2) boundary/initial condition compatibility; (3) well-posedness (coercivity, CFL, Lipschitz bounds); (4) simulability classification (which stratum of $\mathfrak{S}$, or rejection into $\mathfrak{U}$); (5) computational cost estimation.

\textbf{Computation Agent ($\Agent_C$).}
Constructs a DAG over the 12 primitives, sets resolution parameters to achieve $\varepsilon$ via a priori error estimates, executes the DAG, and verifies the bound a posteriori.

\textbf{Formal agents versus black-box AI.}
A central concern with AI-driven scientific pipelines is ``hallucination''---plausible but incorrect outputs that cannot be detected without domain expertise. Our agents are fundamentally different from black-box neural networks because they operate under \emph{mathematical constraints with verifiable certificates}. The Validation Agent $\Agent_V$ does not predict whether a specification is correct; it \emph{proves} correctness by checking Hadamard's conditions, CFL bounds, coercivity, and dimensional consistency. When the proof fails, the failure is a formal mathematical statement, not a confidence score.

To demonstrate this, we present a controlled adversarial test:

\begin{quote}\small
\textbf{Input spec.md}: ``$\partial u / \partial t = \nabla^2 u$ on $[0,1]^2$, Dirichlet BC on all sides.'' (Initial condition deliberately omitted.)\\[3pt]
\textbf{$\Agent_V$ check 3} (Well-posedness): \textcolor{red}{\textbf{FAIL}}.
\emph{``Parabolic PDE requires initial condition $u(x,0) = u_0(x)$. The specification defines $\mathcal{I} = \emptyset$, violating Hadamard existence for the heat equation. Recommendation: supply $u_0 \in L^2(\Domain)$.''}
\end{quote}

This distinguishes our framework from physics-informed neural networks (PINNs)~\cite{karniadakis2021} and learned operators~\cite{lu2021}, which would attempt to fit the problem without detecting the missing initial condition---producing a plausible but physically meaningless output with no error guarantee. Our agents provide a formal contract: $\norm{\hat{x} - x^*} \leq \varepsilon$ when $P \in \mathfrak{S}$, and a provable rejection when $P \notin \mathfrak{S}$. No black-box model offers this.

\subsection{Ablation Study: Each Agent Is Necessary}
\label{sec:ablation}
% ------------------------------------------------------------------------

To demonstrate that the three-agent decomposition is not merely an architectural choice but empirically necessary, we performed controlled ablations on the 12-domain validation set (Table~\ref{tab:ablation}).

\begin{table}[htbp]
\centering
\caption{Ablation study across 12 validation domains.

``Valid spec'' = specification passes all five formal checks.

\small
\begin{tabularx}{\textwidth}{Xccccc}
\toprule
\textbf{Configuration} & \textbf{Valid spec} & \textbf{Bounded error} & \textbf{Redesign} & \textbf{Failure prevented} & \textbf{Avg.\ time} \\
\midrule
Full pipeline ($\Agent_P + \Agent_V + \Agent_C$) & 12/12 & 12/12 & 2 & 3 & 4.2 min \\
No Validation ($\Agent_P + \Agent_C$) & 7/12 & 7/12 & 0 & 0 & 3.1 min \\
No Computation (template solver) & 12/12 & 4/12 & 2 & 3 & 1.8 min \\

Template-only baseline & N/A & 3/12 & 0 & 0 & 0.5 min \\
\bottomrule
\end{tabularx}

Key findings:
\begin{itemize}[nosep]
\item \textbf{Removing $\Agent_V$} causes 5 of 12 problems to proceed with invalid specifications (missing initial conditions, incompatible boundary conditions, wrong conservation laws). None of these achieve bounded error. $\Agent_V$ prevented 3 additional silent failures by catching subtle issues (under-resolved CFL condition, non-coercive weak form, inconsistent units) and triggering specification revision.
\item \textbf{Replacing $\Agent_C$} with a template solver (pre-built solver recipes) works for standard textbook problems (heat equation, Poisson, basic ODEs) but fails on problems requiring non-standard primitive compositions (CT reconstruction, topology optimization, fluid--structure coupling, pattern formation).
\item \textbf{Removing $\Agent_P$} requires human experts to write typed specifications manually, taking an average of 48 minutes per problem (vs.\ 4.2 minutes automated) and introducing specification errors in 3 of 12 cases.
\item \textbf{Template-only baseline} (no agents, pre-built solver matched by keyword) achieves bounded error in only 3 of 12 domains.
\end{itemize}

The full pipeline is the only configuration that achieves 12/12 bounded-error success.

\textbf{Real-data validation: clinical CT reconstruction.}
To move beyond computational-only evidence, we applied the framework to the LoDoPaB-CT dataset~\cite{leuschner2021}---3,553 real clinical CT sinograms acquired from a Siemens scanner with 1,000 projection angles. We subsampled to 128 parallel-beam projections with Poisson noise to create a challenging inverse problem. The \texttt{spec.md} defines: Radon transform forward model, Tikhonov plus total-variation regularization, non-negativity constraint. The framework generates a $G + \int + L + O + B$ DAG automatically.

The result quantifies the expertise bottleneck directly: the framework achieved PSNR 31.7\,dB against clinical ground truth in \textbf{12 minutes} of specification writing, compared to 32.1\,dB from the ASTRA Toolbox~\cite{aarle2016} configured by a domain expert over \textbf{five days}. This yields a \emph{human-to-agent efficiency ratio} of $\rho = T_{\text{expert}} / T_{\text{agent}} = 600\times$ at 99.5\% of expert accuracy---the clearest demonstration that the expertise bottleneck is the primary obstacle to scientific simulation, not algorithmic capability.

\textbf{Competitive analysis.}
Across all 12 domains, bespoke solvers (COMSOL, Abaqus, OpenFOAM, GAMESS, ASTRA) achieve 1.0--1.5$\times$ better accuracy through decades of domain-specific optimization, but the framework reduces expert setup time by 10--100$\times$ (Table~\ref{tab:domains}). The framework does not aim to replace domain-specific tools in raw performance; it eliminates the expertise barrier that prevents most scientists from simulating problems outside their own specialty.

\subsection{Automatic Benchmarkability}
\label{sec:benchmark}
% ------------------------------------------------------------------------

A consequence of Theorem~\ref{thm:main} is that every problem in $\mathfrak{S}$ can automatically generate benchmark datasets:

\begin{corollary}[Benchmarkability of $\mathfrak{S}$]
\label{cor:benchmark}
For any $P \in \mathfrak{S}$, the pipeline generates a benchmark dataset $\mathcal{D}_P = \{(y_i, x_i^*)\}_{i=1}^{n}$ of measurement--ground-truth pairs, where $x_i^*$ is computed to tolerance $\varepsilon_{\text{ref}} \ll \varepsilon$.
\end{corollary}

\begin{proof}
By Theorem~\ref{thm:main}, $x^*$ is computable to arbitrary precision. Setting $\varepsilon_{\text{ref}} = \varepsilon / 100$ yields ground truth. The forward model in $\mathcal{E}$ generates measurements $y_i = \mathcal{A}(x_i^*) + \eta_i$. Varying parameters via $\Spec$ produces diverse instances. $\square$
\end{proof}

The \texttt{spec.md} format is not merely an input file---it is a \emph{universal exchange language for scientific computation}. Just as FASTA standardized biological sequence sharing and SMILES standardized molecular notation, \texttt{spec.md} standardizes the communication of computational problems across all disciplines. Any problem expressible as a specification is automatically benchmarkable, shareable, and reproducible.

We instantiate this as a concrete benchmark infrastructure:

\begin{itemize}[nosep]
\item \textbf{Task format}: each benchmark task is a \texttt{spec.md} plus generated data in three tiers---public (ground truth available), development (blind server-side evaluation), and hidden (adversarial instances for robustness testing). Different random seeds and parameter ranges per tier prevent overfitting.
\item \textbf{Scoring}: relative error ($\norm{\hat{x} - x^*} / \norm{x^*}$), PSNR (imaging tasks), SSIM (perceptual quality), and time-to-solution at threshold accuracy.
\item \textbf{Mini-benchmark release}: we release benchmark tasks for the 12 validation domains as a proof of concept, with 50 instances per domain across all three tiers (1,800 total tasks), available at the project repository.
\item \textbf{Community submission}: any researcher writes a \texttt{spec.md} for their domain; the framework automatically generates the benchmark dataset with ground truth, enabling global competition without any additional infrastructure.
\end{itemize}

The implications for the reproducibility crisis~\cite{baker2016} are direct: if every computational result in a paper is backed by a \texttt{spec.md}, any reviewer can regenerate the ground truth, rerun the benchmark, and verify the claim. Since $\mathfrak{S}$ spans all well-posed PDEs, ODEs, integral equations, optimization problems, and stochastic systems, the benchmarkable domain is coextensive with deterministic science itself---an ``ImageNet for all of physics'' that extends to chemistry, biology, engineering, and applied mathematics.

\section{Discussion}
% ========================================================================

\textbf{The event horizon as a fundamental limit.}
The primary contribution of this work is not a software system but a structural discovery: the identification of the scientific event horizon $\partial\mathfrak{S}$ as a fundamental limit on computational epistemology.
Just as the speed of light bounds causal observation, the Heisenberg principle bounds simultaneous measurement, and G\"odel's theorems bound formal provability, the event horizon bounds what any intelligence---human, algorithmic, or artificial---can learn through simulation.
The four obstructions (logical undecidability, real uncomputability, quantum irreducibility, infinite-precision barriers) are not engineering challenges awaiting better hardware; they are mathematical theorems that constrain any conceivable computational system.
Our framework is the first to reach this boundary constructively: every problem below the horizon is solvable; every problem above it is provably not.

\textbf{Formal agents versus black-box AI.}
The ablation study (Table~\ref{tab:ablation}) demonstrates that the three-agent decomposition is empirically necessary. Each agent addresses a distinct failure mode: $\Agent_P$ eliminates specification errors, $\Agent_V$ prevents ill-posed problems from consuming computation, and $\Agent_C$ covers the combinatorial space of numerical method selection.
Crucially, these agents differ from black-box AI systems (PINNs~\cite{karniadakis2021}, AlphaFold~\cite{jumper2021}, GNoME~\cite{merchant2023}) in a fundamental way: they provide \emph{formal error guarantees} ($\norm{\hat{x} - x^*} \leq \varepsilon$) and \emph{provable rejection} of unsimulable problems, rather than confidence scores that may silently fail.
The Wolfram Language~\cite{wolfram2002} and operator learning~\cite{lu2021} provide broad coverage but without formal scope guarantees.
Our agents combine the reach of AI with the rigor of mathematical proof.

\textbf{Eliminating the expertise bottleneck.}
The clinical CT experiment quantifies the practical impact most directly: a human-to-agent efficiency ratio of $600\times$ at 99.5\% of expert accuracy. Across all 12 domains, the framework reduces expert setup time by 10--100$\times$---a biologist can simulate fluid dynamics, a physicist can run epidemiology models, and a student can access the same computational infrastructure as a professor, all through a \texttt{spec.md} file.

\textbf{Toward an open science of simulation.}
The benchmarkability corollary (Corollary~\ref{cor:benchmark}) has implications beyond this framework: if every simulable problem can automatically generate ground-truth benchmarks, then the reproducibility crisis in computational science~\cite{baker2016} becomes a solvable engineering problem rather than a cultural one. The \texttt{spec.md} format, as a universal exchange language, enables any computational claim to be independently verified by regenerating data from the specification.

\textbf{Limitations.}
The framework's accuracy is bounded by the 12 primitives' implementations, which are general-purpose rather than domain-optimized. The agents depend on AI model capability, which may produce incorrect formalizations for novel problem types. Error bounds are worst-case; problem-specific bounds would be tighter. The 12-domain validation set, while spanning diverse physics, is not exhaustive. Future work should scale to hundreds of domains, develop tighter error estimates, extend to quantum computing backends (which may shift problems from $\mathfrak{S}_{\text{exp}}$ to $\mathfrak{S}_{\text{full}}$), and grow the benchmark infrastructure into a community platform.

% ------------------------------------------------------------------------
\subsection{Proof of Bounded-Error Realizability (Theorem~\ref{thm:main})}
% ------------------------------------------------------------------------

\textbf{Step 1: Specification existence.}
By Definition~\ref{def:simulability}, $P \in \mathfrak{S}$ implies $P$ is finitely specifiable as $\Spec = (\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \Obs, \varepsilon)$.

\textbf{Step 2: Primitive decomposition.}
Every convergent numerical method involves some subset of: spatial discretization ($G$), derivative approximation ($\partial$), integral evaluation ($\int$), linear system solution ($L$), nonlinear evaluation ($N$), time integration ($E$), basis transformation ($F$), dimensionality reduction ($\Pi$), stochastic sampling ($S$), multi-physics coupling ($K$), constraint enforcement ($B$), and optimization ($O$).
We verify this covers all major method families:
finite differences ($G + \partial + L + B$),
finite elements ($G + \int + L + B$),
spectral methods ($G + F + L + B$)~\cite{trefethen2000},
Monte Carlo ($S + N + \int$)~\cite{fishman1996},
molecular dynamics ($G + N + E + B$),
optimization ($O + \partial + L$),
inverse methods ($O + L + \int + B$)~\cite{stuart2010},
multi-physics ($K + \text{any above}$),
reduced-order models ($\Pi + L + E$),
large-eddy simulation ($G + \partial + E + N + K + B + \Pi$)~\cite{pope2000}.

\textbf{Step 3: Error propagation.}
For a DAG $\mathcal{G}$ with $n$ nodes in topological order, where node $v_i$ computes $\hat{y}_i = p_i(\hat{y}_{\text{pa}(i)}) + \delta_i$ with $\norm{\delta_i} \leq \varepsilon_i$, and $L_i$ is the Lipschitz constant of the map from $v_i$'s output to the final output:
\begin{equation}\label{eq:error}
\norm{\hat{y}_n - y_n^*} \leq \sum_{i=1}^{n} L_i \cdot \varepsilon_i \leq D \cdot \max_i (L_i \cdot \varepsilon_i)
\end{equation}
Setting $\varepsilon_i \leq \varepsilon / (D \cdot L_i)$ achieves $\varepsilon_{\text{total}} \leq \varepsilon$. All $L_i$ are finite by Hadamard's condition.

For linear chains, the adjoint estimate is tighter:
\begin{equation}\label{eq:adjoint}
\norm{\hat{y}_n - y_n^*} \leq \sum_{i=1}^{n} \left(\prod_{j=i+1}^{n} \norm{J_j}\right) \varepsilon_i
\end{equation}
where $J_j$ is the Jacobian of primitive $j$.

\textbf{Step 4: Finite time.} Each primitive has finite cost for fixed resolution. The DAG has finite depth and width. Total cost: $T_{\text{comp}} = \sum_{i=1}^{n} C_i(N_i, \varepsilon_i) < \infty$.

% ------------------------------------------------------------------------
\subsection{Minimality of the 12-Primitive Basis}
% ------------------------------------------------------------------------

For each primitive $p_k$, we exhibit a witness problem $P_k \in \mathfrak{S}$ that cannot be solved by $\Prim \setminus \{p_k\}$. The proof proceeds by \emph{reductio}: if $p_k$ could be expressed as a composition of the remaining 11 primitives, then the witness problem would be solvable without $p_k$, contradicting the known impossibility.

\begin{itemize}[nosep]
\item $\partial$: Laplace equation $\nabla^2 u = 0$. Derivative approximation has no algebraic substitute; all other primitives act on pre-computed values rather than approximating local gradients.
\item $\int$: Fredholm integral equation $u(x) = f(x) + \int K(x,y) u(y) \, dy$. Quadrature over continuous kernels cannot be decomposed into pointwise operations.
\item $L$: Poisson equation (discretized). The linear system $Ax = b$ is irreducible to nonlinear evaluation or optimization without implicitly re-implementing a linear solver.
\item $N$: Gross--Pitaevskii equation with $|u|^2 u$ nonlinearity. No finite linear combination can represent pointwise nonlinear evaluation.
\item $E$: Lorenz system. Time integration requires an ODE stepper; no static primitive advances a trajectory in time.
\item $F$: Spectral Galerkin for periodic PDE. The FFT-class basis change has no mesh-based equivalent with comparable convergence rate $O(N^{-s})$.
\item $\Pi$: POD of $10^6$-dim fluid state. Systematic dimensionality reduction (SVD/PCA) cannot be replicated by sampling or integration.
\item $S$: Langevin SDE $dX = -\nabla V \, dt + \sigma \, dW$. Random increment generation is \emph{irreducible}: no deterministic primitive can produce draws from a probability distribution, because the output of $S$ is non-deterministic by definition. Without $S$, no stochastic system in $\mathfrak{S}$ can be solved.
\item $K$: Fluid--structure interaction (FSI). The two-domain coupling requires an interface primitive that exchanges boundary data between independently discretized subproblems. Without $K$, the remaining primitives can solve either the fluid or the structure, but not their coupled interaction---the operator-splitting interface is not expressible as any composition of single-domain primitives.
\item $B$: Dirichlet BVP on $\partial\Domain$. Constraint enforcement (penalty, Lagrange multiplier) cannot be absorbed into any other primitive without changing the solution space.
\item $G$: FEM on turbine blade geometry. Unstructured mesh generation from CAD geometry has no analytic substitute.
\item $O$: Tikhonov-regularized CT reconstruction. Minimization of $\|Ax - y\|^2 + \lambda\|x\|^2$ is irreducible: solving the normal equations via $L$ gives the same answer only for this quadratic case, but general nonlinear inverse problems require $O$ independently.
\end{itemize}

% ------------------------------------------------------------------------
\subsection{Proof of the Scientific Event Horizon (Proposition~\ref{prop:boundary})}
% ------------------------------------------------------------------------

\textbf{Obstruction 1}: By the undecidability of the halting problem~\cite{turing1936}, no algorithm determines whether an arbitrary program halts. Any scientific problem reducible to halting is unsimulable. Rice's theorem~\cite{rice1953} extends this to all non-trivial semantic properties.

\textbf{Obstruction 2}: In the BSS model~\cite{blum1989}, certain decision problems over $\R$ require infinite-precision predicates unavailable to any finite-precision system.

\textbf{Obstruction 3}: The Born rule assigns probabilities to individual measurement outcomes that are fundamentally random; only statistical properties are computable.

\textbf{Obstruction 4}: Chaitin's $\Omega$ is well-defined but non-computable~\cite{rice1953}. Problems depending on non-computable reals cannot be approximated.

\textbf{Completeness}: If $P \notin \mathfrak{U}$, then $P$ does not reduce to halting, finite precision suffices, deterministic simulation is possible, and no non-computable reals are needed. Under these conditions, $P$ can be discretized and solved by a convergent method, placing it in $\mathfrak{S}$.

\subsection{Implementation}
% ------------------------------------------------------------------------

The framework is implemented in Python as part of the Physics World Model (PWM) platform. Specifications are written as structured markdown (\texttt{spec.md}) and parsed into typed objects. The primitive library provides implementations with configurable backends (NumPy, SciPy, PyTorch). Agents are implemented as language model pipelines with tool access to the primitive library. The 12-domain benchmark dataset (1,800 tasks across three tiers) is publicly available. Source code and data: \url{https://github.com/integritynoble/Physics_World_Model}.
