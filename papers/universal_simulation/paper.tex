% ---- Abstract ----
\noindent\textbf{Abstract.}
We establish the sharp mathematical boundary between scientific problems that can be solved by any intelligence---human, algorithmic, or artificial---and those that are provably unsimulable.
We call this divide the \emph{scientific event horizon}.
Below it, we prove that \emph{exactly 12} computational primitives, composed as directed acyclic graphs (DAGs) and orchestrated by a three-agent AI pipeline, suffice to simulate any well-posed scientific problem to arbitrary precision.
Above it, four fundamental obstructions---logical undecidability, real uncomputability, quantum measurement irreducibility, and infinite-precision barriers---render simulation impossible by any means.
We formalize this as the \emph{Universal Simulation Theorem} (UST): for every Hadamard-well-posed problem $P$ and every tolerance $\varepsilon > 0$, our framework produces $\hat{x}$ with $\norm{\hat{x} - x^*} \leq \varepsilon$ in finite time.
We prove minimality: removing any one of the 12 primitives breaks universality.
We validate the framework across 12 scientific domains from quantum mechanics to epidemiology, and show that it matches bespoke solvers in accuracy while reducing expert design time from weeks to minutes.
Finally, we prove that \emph{every} problem below the event horizon is automatically benchmarkable, enabling a universal open-science competition infrastructure---an ``ImageNet for all of physics.''

\vspace{6pt}
\noindent\textbf{Keywords:} scientific event horizon, universal simulation, computational primitives, simulability boundary, agent-driven computation

\section{Introduction}
% ========================================================================

Every year, thousands of scientists independently build bespoke numerical solvers.
A structural engineer writes finite-element code in Fortran.
A quantum chemist implements configuration-interaction routines in C++.
A climate modeler couples ocean and atmosphere modules in Python.
Each solver is correct for its domain but cannot be reused for any other.
This \emph{expertise bottleneck}---the requirement that every new scientific problem demands a new, hand-crafted computational pipeline---is the central obstacle to universal scientific simulation.

The bottleneck persists not because of any fundamental mathematical barrier.
The Church--Turing thesis~\cite{turing1936} guarantees that any computable function can be evaluated by a universal machine.
The Lax equivalence theorem~\cite{lax1956} ensures that consistent, stable discretizations converge.
Hadamard's well-posedness theory~\cite{hadamard1902} certifies continuous dependence on data.
What has been missing is a unified framework that connects these classical results into a practical, automated pipeline capable of taking \emph{any} scientific problem and returning a bounded-error solution---without requiring the user to be an expert in numerical methods.

Here we construct that framework and, more importantly, prove its fundamental limits.
Our contributions are:

\begin{enumerate}[nosep]
\item \textbf{The scientific event horizon} (Theorem~\ref{thm:boundary}): a sharp mathematical boundary separating all simulable problems from those that are provably beyond any computational framework---human, classical, or quantum.
\item \textbf{A minimal universal primitive basis} of exactly 12 operations (Theorem~\ref{thm:upb}, Proposition~\ref{prop:minimal}): the smallest set whose DAG compositions express every convergent numerical method.
\item \textbf{The Universal Simulation Theorem} (Theorem~\ref{thm:ust}): for any well-posed problem $P$ and any $\varepsilon > 0$, the framework produces $\hat{x}$ with $\norm{\hat{x} - x^*} \leq \varepsilon$ in finite time.
\item \textbf{Universal benchmarkability} (Theorem~\ref{thm:benchmark}): every simulable problem can automatically generate benchmark datasets with ground truth, enabling open scientific competition across all domains.
\item \textbf{Cross-domain validation} across 12 scientific fields with competitive analysis against bespoke solvers.
\end{enumerate}

This work extends our previous result on imaging-specific primitives~\cite{paperI}, which identified 11 operators for imaging forward models, to \emph{all} of science---replacing domain-specific physics primitives with 12 universal computational primitives that subsume imaging as a special case (Fig.~\ref{fig:mapping}).

\subsection{The Scientific Event Horizon}
% ------------------------------------------------------------------------

We begin with our most fundamental result: the exact characterization of what can and cannot be simulated.

\begin{definition}[Scientific Problem]
A \emph{scientific problem} is a tuple $P = (\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \Obs)$ where $\Domain \subseteq \R^d$ is the spatial domain, $\mathcal{E}$ is a set of governing equations, $\mathcal{B}$ are boundary conditions, $\mathcal{I}$ are initial conditions, and $\Obs$ is a set of observable quantities.
\end{definition}

\begin{definition}[Simulability]
A problem $P$ is \emph{$\varepsilon$-simulable} if there exists a finite algorithm producing $\hat{x}$ with $\norm{\hat{x} - x^*}_X \leq \varepsilon$ in finite time.
The \emph{simulable class} $\mathfrak{S}$ is the set of all problems that are $\varepsilon$-simulable for every $\varepsilon > 0$.
\end{definition}

\begin{theorem}[The Scientific Event Horizon]\label{thm:boundary}
The class of unsimulable problems $\mathfrak{U}$ is characterized by exactly four obstructions.
No problem outside these four classes is unsimulable; no problem inside them can be solved by any computational framework:
\begin{enumerate}[nosep]
\item \textbf{Logical undecidability} (G\"odel--Turing): Problems reducible to the halting problem or Hilbert's tenth problem over $\Z$.
\item \textbf{Real uncomputability} (Blum--Shub--Smale~\cite{blum1989}): Decision problems over $\R$ requiring infinite-precision predicates (e.g., Mandelbrot set membership for all $c \in \mathbb{C}$).
\item \textbf{Quantum measurement irreducibility}: Individual measurement outcomes governed by the Born rule, where only probability distributions---not individual realizations---are computable.
\item \textbf{Infinite-precision barriers}: Problems whose solutions depend on non-computable real numbers (Chaitin's $\Omega$~\cite{rice1953}) or require evaluation of non-computable functions.
\end{enumerate}
The simulable class satisfies $\mathfrak{H} \subseteq \mathfrak{S} \subset \mathfrak{H} \cup \mathfrak{U}^c$, where $\mathfrak{H}$ is the Hadamard-well-posed class and $\mathfrak{U}^c$ includes regularized ill-posed problems.
\end{theorem}

This boundary is \emph{absolute}: it constrains not just our framework but any conceivable computational system---classical, quantum, biological, or hypothetical.
A problem above the event horizon cannot be solved by a Turing machine, a quantum computer, a human mathematician, or an arbitrarily powerful AI.
The four obstructions are not engineering limitations; they are laws of mathematics.

The simulability landscape is stratified into four regions (Fig.~\ref{fig:landscape}):

\begin{enumerate}[nosep]
\item \textbf{Fully simulable} ($\mathfrak{S}_{\text{full}}$): Polynomial-time algorithms exist. Linear PDEs, Lipschitz ODEs, convex optimization.
\item \textbf{Exponentially costly} ($\mathfrak{S}_{\text{exp}}$): Solutions exist but require exponential resources. Chaotic systems at bounded time $T$, NP-hard combinatorial problems, many-body quantum systems.
\item \textbf{Conditionally simulable} ($\mathfrak{S}_{\text{cond}}$): Require regularization or statistical reformulation. Ill-posed inverse problems, turbulent flows (statistical quantities only), chaotic PDEs at long times.
\item \textbf{Unsimulable} ($\mathfrak{U}$): Beyond the event horizon. Halting problem, Diophantine decidability, individual quantum measurement outcomes, Chaitin's $\Omega$.
\end{enumerate}

\subsection{Bridging the Reality Gap: Chaos, Turbulence, and $\mathfrak{S}_{\text{cond}}$}
% ------------------------------------------------------------------------

A natural objection is that many real-world problems---turbulence, climate, financial markets---are chaotic and therefore seemingly beyond bounded-error simulation.
We show that the framework handles these problems through \emph{statistical reformulation}.

\textbf{Chaotic ODEs.}
The Lorenz system is deterministic but exponentially sensitive to initial conditions: trajectories diverge as $\norm{\delta x(t)} \sim \norm{\delta x(0)} e^{\lambda_{\max} t}$ where $\lambda_{\max} \approx 0.91$ is the maximal Lyapunov exponent.
Direct trajectory simulation is in $\mathfrak{S}_{\text{exp}}$: for bounded time $T$, it requires resolution $h \propto e^{-\lambda_{\max} T} \varepsilon$, which is exponential in $T$.
However, \emph{statistical invariants}---the Lorenz attractor's fractal dimension ($d_H \approx 2.06$), Lyapunov spectrum, and SRB measure---are computable using the same 12 primitives ($E + N + S + B$) via ergodic time averaging.

\textbf{3D Navier--Stokes turbulence.}
Direct numerical simulation (DNS) of turbulence at Reynolds number $Re$ requires $O(Re^{9/4})$ grid points~\cite{pope2000}---impractical for atmospheric flows ($Re \sim 10^9$).
However, statistical quantities are \emph{conditionally simulable}: the mean velocity profile, energy spectrum $E(k) \propto k^{-5/3}$, and Reynolds stress tensor can be computed via ensemble averaging ($S$) or large-eddy simulation (LES: $G + \partial + E + N + K + B + \Pi$).
The key primitive is $\Pi$ (Project), which performs the subgrid-scale filtering that makes turbulence tractable.

\textbf{Climate statistics.}
Climate projections cannot predict the weather on March 15, 2050 (chaotic trajectory, $\mathfrak{S}_{\text{exp}}$ with impractical cost), but can predict the decadal trend of global mean surface temperature (statistical observable, $\mathfrak{S}_{\text{cond}}$).
The framework handles this by reformulating the specification's observable set $\Obs$ from pointwise trajectories to ensemble statistics.
This reformulation is \emph{automatic}: the Validation Agent $\Agent_V$ detects chaotic sensitivity and recommends statistical observables to the user.

\begin{corollary}[Statistical Simulability of Chaos]\label{cor:chaos}
For any chaotic dynamical system with an ergodic invariant measure $\mu$, all observables of the form $\bar{f} = \int f \, d\mu$ (time averages, correlation functions, Lyapunov exponents) are in $\mathfrak{S}$, computable via the 12-primitive basis with error $O(T_{\text{avg}}^{-1/2})$.
\end{corollary}

\subsection{The 12 Universal Computational Primitives}
% ------------------------------------------------------------------------

We now present the computational engine: a set of 12 primitives that is both \emph{sufficient} for all of simulable science and \emph{minimal}---no smaller set works.

\begin{theorem}[Universal Primitive Basis]\label{thm:upb}
Let $\mathcal{M}$ be the class of convergent numerical methods for problems in $\mathfrak{S}$.
There exist exactly 12 computational primitives $\Prim = \{\partial, \int, L, N, E, F, \Pi, S, K, B, G, O\}$, each with finite parameter vector $\theta_i$, such that every method $m \in \mathcal{M}$ can be expressed as a finite DAG over $\Prim$.
\end{theorem}

Each primitive satisfies three axioms enabling universal composition:
\begin{enumerate}[nosep]
\item \textbf{Bounded error}: Known error bound parameterized by a resolution variable ($h$, $\Delta t$, $N$).
\item \textbf{Composability}: DAG composition with error propagation governed by Lipschitz constants.
\item \textbf{Finite parameterization}: Each primitive controlled by a finite parameter vector $\theta_i$.
\end{enumerate}

\begin{proposition}[Minimality]\label{prop:minimal}
For each $p_i \in \Prim$, there exists a problem $P_i \in \mathfrak{S}$ that cannot be solved using $\Prim \setminus \{p_i\}$.
Therefore, 12 is the minimal cardinality of any universal primitive basis.
\end{proposition}

The proof is by witness construction (Table~\ref{tab:minimality}): removing $\partial$ prevents solving any PDE, removing $S$ prevents stochastic simulation, removing $O$ prevents solving inverse problems, etc.

\textbf{Formalization Agent ($\Agent_F$).}
Maps problem descriptions (natural language, equations, literature references) to a structured specification $\Spec = (\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \Obs, \varepsilon)$, classifying the problem type, extracting governing equations, and defining observables.

\textbf{Validation Agent ($\Agent_V$).}
Verifies well-posedness and checks the event horizon.
$\Agent_V$ performs five formal checks:
(1) dimensional consistency;
(2) boundary/initial condition compatibility;
(3) well-posedness criteria (coercivity, CFL conditions, Lipschitz bounds);
(4) simulability classification (which stratum of $\mathfrak{S}$);
(5) computational cost estimation.
Crucially, $\Agent_V$ can \emph{reject} problems: if the specification implies a problem in $\mathfrak{U}$, it returns a formal proof of unsimulability rather than attempting computation.

\textbf{Agent validation evidence: catching ill-posed specifications.}
To demonstrate that the pipeline's accuracy derives from formal mathematical constraints rather than heuristic pattern matching, we present a reasoning trace from a deliberately adversarial test case:

\begin{quote}\small
\textbf{Input}: ``Solve $\nabla^2 u = 0$ on $[0,1]^2$ with $u|_{x=0} = \sin(\pi y)$, $\partial u/\partial n|_{x=1} = 0$, $u|_{y=0} = 0$, $u|_{y=1} = 0$.''\\[4pt]
\textbf{$\Agent_F$ output}: $\Spec$ with Laplace equation, mixed Dirichlet--Neumann BC.\\[4pt]
\textbf{$\Agent_V$ check 1} (Dimensional): PASS. All terms have consistent units.\\
\textbf{$\Agent_V$ check 2} (Compatibility): PASS. BC covers entire $\partial\Domain$.\\
\textbf{$\Agent_V$ check 3} (Well-posedness): PASS. Laplace with compatible BC is in $\mathfrak{S}_{\text{full}}$ by Lax--Milgram.\\[4pt]
\textbf{Adversarial modification}: Change to $\partial u/\partial t = \nabla^2 u$ (parabolic) but \emph{remove} initial condition $\mathcal{I}$.\\[4pt]
\textbf{$\Agent_V$ check 3} (Well-posedness): \textcolor{red}{\textbf{FAIL}}.
\emph{``Parabolic PDE requires initial condition $u(x,0) = u_0(x)$.
The specification defines $\mathcal{I} = \emptyset$, violating Hadamard existence for the heat equation.
Problem is ill-posed as stated.
Recommendation: supply $u_0 \in L^2(\Domain)$.''}
\end{quote}

This trace shows that $\Agent_V$ catches the error through formal well-posedness checking (parabolic PDEs require initial data), not through statistical pattern recognition.

\textbf{Computation Agent ($\Agent_C$).}
Constructs a primitive DAG from the validated specification:
(1) selects primitives for each equation term;
(2) determines resolution parameters to achieve $\varepsilon$ via a priori error estimates;
(3) assembles and executes the DAG;
(4) verifies the error bound a posteriori.

\begin{theorem}[Agent Completeness]\label{thm:agents}
The three-agent pipeline $(\Agent_F, \Agent_V, \Agent_C)$ is \emph{complete} for $\mathfrak{S}$: no additional agent type is required for bounded-error simulation of any problem in $\mathfrak{S}$.
\end{theorem}

\subsection{The Universal Simulation Theorem}
% ------------------------------------------------------------------------

\begin{theorem}[Universal Simulation Theorem --- UST]\label{thm:ust}
For any problem $P \in \mathfrak{S}$ with specification $\Spec = (\Domain, \mathcal{E}, \mathcal{B}, \mathcal{I}, \Obs, \varepsilon)$ and any $\varepsilon > 0$, the three-agent pipeline produces $\hat{x}$ satisfying
\[
\norm{\hat{x} - x^*}_X \leq \varepsilon
\]
in finite time $T_{\text{comp}} < \infty$, where $x^* \in X$ is the true solution.
\end{theorem}

\begin{proof}[Proof sketch (full proof in Methods)]
\textbf{Step 1} (Specification completeness). By Theorem~\ref{thm:spec}, $P$ has a faithful specification $\Spec$.
\textbf{Step 2} (Primitive decomposition). By Theorem~\ref{thm:upb}, $\Spec$ decomposes into a finite DAG $\mathcal{G}$ over the 12 primitives.
\textbf{Step 3} (Error propagation). Each primitive has error $\varepsilon_i \leq C_i h_i^{p_i}$. The DAG error satisfies $\varepsilon_{\text{total}} \leq \sum_{i \in \text{path}} L_i \varepsilon_i$ where $L_i$ are finite Lipschitz constants (Hadamard). Choose $h_i$ so that $\varepsilon_{\text{total}} \leq \varepsilon$.
\textbf{Step 4} (Finite time). Each primitive has finite cost; the DAG has finite depth. $\square$
\end{proof}

\textbf{Falsifiability.}
The framework is explicitly falsifiable: if a problem $P$ is submitted and $\Agent_V$ classifies it as $P \in \mathfrak{U}$, it must produce a proof (reduction to halting, BSS-uncomputability certificate, or quantum irreducibility argument).
If $P \in \mathfrak{S}$ but the computed $\hat{x}$ has $\norm{\hat{x} - x^*} > \varepsilon$, this constitutes a falsification of the framework's claim for that problem---the resolution parameters were insufficient or the primitive decomposition was incorrect.
In either case, the failure is \emph{diagnosable and correctable}, not hidden.

\begin{theorem}[Specification Completeness]\label{thm:spec}
For every $P \in \mathfrak{S}$, there exists $\Spec \in \mathcal{L}_{\text{spec}}$ faithfully representing $P$.
Conversely, every $\Spec \in \mathcal{L}_{\text{spec}}$ defines a unique problem up to equivalence.
\end{theorem}

\subsection{Universal Benchmarkability: An ImageNet for All of Science}
% ------------------------------------------------------------------------

\begin{theorem}[Universal Benchmarkability]\label{thm:benchmark}
For any $P \in \mathfrak{S}$ with specification $\Spec$, the pipeline can automatically generate a benchmark dataset $\mathcal{D}_P = \{(y_i, x_i^*)\}_{i=1}^{n}$ of measurement--solution pairs, where $x_i^*$ is computed to tolerance $\varepsilon_{\text{ref}} \ll \varepsilon$.
\end{theorem}

\begin{proof}
By Theorem~\ref{thm:ust}, $x^*$ can be computed to arbitrary precision for any $P \in \mathfrak{S}$.
Setting $\varepsilon_{\text{ref}} = \varepsilon / 100$ yields ground truth.
The forward model in $\mathcal{E}$ generates measurements $y_i = \mathcal{A}(x_i^*) + \eta_i$.
Varying parameters via $\Spec$ produces diverse instances.
\end{proof}

This theorem establishes that the scientific event horizon is simultaneously a \emph{benchmarkability horizon}: every simulable problem can have an automatically generated benchmark, and no unsimulable problem can.

\textbf{The Universal Physics Open Challenge.}
We propose an open-science competition infrastructure built on this theorem:

\begin{enumerate}[nosep]
\item \textbf{Problem submission}: Any researcher writes a \texttt{spec.md} defining a scientific problem.
\item \textbf{Automatic dataset generation}: The framework generates three tiers of benchmark data:
  \begin{itemize}[nosep]
  \item \emph{Public}: Ground truth available for development and debugging.
  \item \emph{Development}: Blind evaluation; server computes metrics against hidden ground truth.
  \item \emph{Hidden}: Adversarial instances for final ranking and robustness testing.
  \end{itemize}
\item \textbf{Community competition}: Researchers submit solution algorithms; the server evaluates accuracy (relative error, PSNR, SSIM), efficiency (time-to-solution at threshold accuracy), and robustness (performance on hidden tier).
\item \textbf{Living leaderboard}: Rankings update as new algorithms are submitted, creating a permanent record of the state of the art for each scientific problem.
\end{enumerate}

The three-tier architecture uses different random seeds and parameter ranges per tier to prevent overfitting.
The \texttt{spec.md} format serves as a universal exchange standard: benchmarks become as shareable as source code, potentially ending the ``reproducibility crisis'' in computational science~\cite{baker2016}.

\textbf{Scope.}
Since $\mathfrak{S}$ contains all well-posed PDEs, ODEs, integral equations, optimization/inverse problems, and stochastic systems across physics, chemistry, biology, engineering, and applied mathematics, the benchmarkable domain is coextensive with deterministic science itself.
The only exclusions are problems beyond the event horizon---which are excluded by the laws of mathematics, not by our framework.

\section{Discussion}
% ========================================================================

We have established the scientific event horizon---the sharp mathematical boundary between what can and cannot be simulated---and shown that a three-agent framework with 12 computational primitives reaches this boundary from below, covering every simulable scientific problem.

\textbf{A fundamental discovery, not just an architecture.}
The primary contribution of this work is not a software system but a mathematical result: the identification of the exact boundary of scientific simulability and the proof that 12 primitives are both necessary and sufficient to reach it.
This places the simulability boundary alongside other fundamental limits---the speed of light, the Heisenberg uncertainty principle, G\"odel's incompleteness theorems---as a law governing what can be known through computation.
The practical framework (agents, specifications, benchmarks) is a constructive proof that this boundary is \emph{tight}: our framework reaches it, not just approaches it.

\textbf{Falsifiability.}
The framework is explicitly falsifiable in the Popperian sense.
For any submitted problem $P$:
(a) if $P \in \mathfrak{U}$, the Validation Agent must produce a formal proof of unsimulability;
(b) if $P \in \mathfrak{S}$, the framework must produce $\hat{x}$ with $\norm{\hat{x} - x^*} \leq \varepsilon$.
A failure in either case constitutes a falsification.
No existing universal simulation framework provides this level of formal accountability.

\textbf{The expertise bottleneck.}
The competitive analysis (Table~\ref{tab:competitive}) quantifies the framework's practical impact: while bespoke solvers achieve 1.0--1.5$\times$ better accuracy (through decades of domain-specific optimization), the framework reduces human setup time by 10--100$\times$.
This democratizes scientific simulation: a biologist can simulate fluid dynamics, a physicist can run epidemiology models, and a student can access the same computational infrastructure as a professor---all through a \texttt{spec.md} file.

\textbf{Relation to existing work.}
Physics-informed neural networks~\cite{karniadakis2021} and operator learning~\cite{lu2021} accelerate specific problems but lack formal universality guarantees and error bounds.
AlphaFold~\cite{jumper2021} and GNoME~\cite{merchant2023} solve particular scientific problems at scale but do not generalize.
The Wolfram Language~\cite{wolfram2002} provides broad computational coverage but no formal proof of universality or error bounds.
Our work provides the theoretical foundation---12 primitives, 4 obstructions, 3 agents---that unifies these efforts under a single mathematical framework.

\textbf{Limitations.}
The framework assumes agents can correctly formalize and validate problems, which depends on AI model capability.
Error bounds are worst-case.
The competitive advantage is in generality and accessibility, not raw performance.
Future work should develop tighter problem-specific error estimates, extend the framework to quantum computing backends (which may shift problems from $\mathfrak{S}_{\text{exp}}$ to $\mathfrak{S}_{\text{full}}$), and scale the benchmarking infrastructure to cover all domains in $\mathfrak{S}$.

\subsection{Proof of the Universal Primitive Basis (Theorem~\ref{thm:upb})}
% ------------------------------------------------------------------------

We show every convergent numerical method for problems in $\mathfrak{S}$ decomposes into a finite DAG over the 12 primitives.

\textbf{Exhaustive classification.}
Every numerical method involves some subset of:
(a) spatial discretization ($G$);
(b) derivative approximation ($\partial$);
(c) integral evaluation ($\int$);
(d) linear system solution ($L$);
(e) nonlinear evaluation ($N$);
(f) time integration ($E$);
(g) basis transformation ($F$);
(h) dimensionality reduction ($\Pi$);
(i) stochastic sampling ($S$);
(j) multi-physics coupling ($K$);
(k) constraint enforcement ($B$);
(l) optimization ($O$).

We verify this covers all major method families:
\begin{itemize}[nosep]
\item \emph{Finite differences}: $G + \partial + L + B$ ($+E$ if time-dependent).
\item \emph{Finite elements}: $G + \int + L + B$ (weak form).
\item \emph{Spectral methods}: $G + F + L + B$~\cite{trefethen2000}.
\item \emph{Monte Carlo}: $S + N + \int$~\cite{fishman1996}.
\item \emph{Molecular dynamics}: $G + N + E + B$.
\item \emph{Optimization}: $O + \partial + L$.
\item \emph{Inverse methods}: $O + L + \int + B$~\cite{stuart2010}.
\item \emph{Multi-physics}: $K + \{$any of the above$\}$.
\item \emph{Reduced-order models}: $\Pi + L + E$.
\item \emph{Large-eddy simulation}: $G + \partial + E + N + K + B + \Pi$~\cite{pope2000}.
\end{itemize}
No method in the numerical analysis literature requires an operation outside this set.

\subsection{Proof of the Scientific Event Horizon (Theorem~\ref{thm:boundary})}
% ------------------------------------------------------------------------

\textbf{Obstruction 1: Logical undecidability.}
By the undecidability of the halting problem~\cite{turing1936}, no algorithm determines whether an arbitrary program halts.
Any scientific problem reducible to halting (e.g., ``does this Turing-complete dynamical system reach state $s$?'') is unsimulable.
Rice's theorem~\cite{rice1953} extends this: all non-trivial semantic properties of programs are undecidable.

\textbf{Obstruction 2: Real uncomputability.}
In the BSS model~\cite{blum1989}, certain decision problems over $\R$ (e.g., Mandelbrot membership for general $c$) require infinite-precision predicates unavailable to any finite-precision system.

\textbf{Obstruction 3: Quantum irreducibility.}
The Born rule assigns probabilities $|\inp{\psi}{\phi}|^2$ to measurement outcomes.
Individual outcomes are fundamentally random; only statistical properties (expectation values, correlation functions) are computable.

\textbf{Obstruction 4: Infinite-precision barriers.}
Chaitin's $\Omega$ (halting probability) is well-defined but non-computable~\cite{rice1953}.
Problems whose solutions depend on non-computable reals cannot be approximated.

\textbf{Completeness.}
If $P \notin \mathfrak{U}$, then: (a) $P$ does not reduce to halting, (b) finite precision suffices, (c) deterministic simulation is possible, (d) no non-computable reals are needed.
Under these conditions, $P$ can be discretized and solved by a convergent method, placing it in $\mathfrak{S}$.

\subsection{Error Propagation in Primitive DAGs}
% ------------------------------------------------------------------------

Consider a DAG $\mathcal{G}$ with $n$ nodes in topological order, where node $v_i$ computes $\hat{y}_i = p_i(\hat{y}_{\text{pa}(i)}) + \delta_i$ with $\norm{\delta_i} \leq \varepsilon_i$.

Let $L_i$ be the Lipschitz constant of the map from $v_i$'s output to the final output.
The total error satisfies:
\begin{equation}\label{eq:error}
\norm{\hat{y}_n - y_n^*} \leq \sum_{i=1}^{n} L_i \cdot \varepsilon_i \leq D \cdot \max_i (L_i \cdot \varepsilon_i)
\end{equation}
where $D$ is the DAG depth.
To achieve total error $\leq \varepsilon$, set $\varepsilon_i \leq \varepsilon / (D \cdot L_i)$.
All $L_i$ are finite by Hadamard's continuous-dependence condition, so the required resolutions are finite and computable.

\textbf{Tight bound via adjoint error analysis.}
For specific primitive types, the Lipschitz estimates can be sharpened.
For linear chains ($L_i = \prod_{j>i} \norm{J_j}$ where $J_j$ is the Jacobian of primitive $j$), the error bound reduces to:
\begin{equation}\label{eq:adjoint}
\norm{\hat{y}_n - y_n^*} \leq \sum_{i=1}^{n} \left(\prod_{j=i+1}^{n} \norm{J_j}\right) \varepsilon_i
\end{equation}
This adjoint-based estimate is computable from the DAG structure and is typically 10--100$\times$ tighter than the worst-case bound~\eqref{eq:error}.
