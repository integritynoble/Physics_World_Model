## 1. Physics & Forward Model

**Modality:** Polarization Imaging (Mueller Matrix / Stokes Imaging)

**Physical principle:** Polarization imaging characterizes how a sample modifies the polarization state of light, encoding information about optical anisotropy (birefringence), depolarization, and diattenuation. The complete polarimetric response of a sample is described by its 4×4 Mueller matrix M, which maps input Stokes vectors S_in to output Stokes vectors S_out = M·S_in. Polarized light is generated by a polarization state generator (PSG) and analyzed by a polarization state analyzer (PSA); by acquiring images under multiple input/output polarization combinations, the full Mueller matrix can be measured at each pixel.

**Forward model:**
```
I_{k}(x, y) = a_k^T · M(x, y) · g_k + n

where:
  I_k(x, y)   — intensity at pixel (x,y) for measurement configuration k
  M(x, y)     — 4×4 Mueller matrix at pixel (x,y)
  g_k         — Stokes vector of input polarization state k (from PSG)
  a_k         — analysis vector of PSA for measurement k
  n           — detector noise

Full system: I = W · vec(M), where W is the measurement matrix of size K×16
```

**Inverse problem:** Recover the spatially-resolved Mueller matrix M(x,y) from a set of K≥16 intensity images acquired under different PSG/PSA configurations; often the reduced problem of recovering the retardance/depolarization images is of primary interest.

## 2. Mismatch Parameters & Benchmark Structure

**Spec notation:** P(polarized light source + PSG) → F(Mueller matrix interaction) → D(camera + PSA)

**Key mismatch parameters:**
- `psg_calibration_error`: angular error in PSG waveplate orientation; nominal 0°, perturbed ±1°
- `psa_calibration_error`: angular error in PSA waveplate orientation; nominal 0°, perturbed ±1°
- `depolarization_crosstalk`: stray light depolarization from optical surfaces; nominal 0%, perturbed to 5%
- `wavelength_bandwidth`: spectral bandwidth of illumination; nominal quasi-monochromatic (Δλ=1 nm), perturbed to broadband (Δλ=20 nm)

**Dataset format:**
- `x_true: (H, W, 16)` — per-pixel vectorized 4×4 Mueller matrix (or reduced representation), dimensionless
- `y: (K, H, W)` — K intensity images under K different PSG/PSA configurations

## 3. Reconstruction Methods & Leaderboard

| Algorithm | Type | Reference | Appropriateness |
|-----------|------|-----------|-----------------|
| Least-squares Mueller matrix inversion | Classical | Goldstein, Polarized Light, CRC Press (2011) | Direct pseudo-inverse of measurement matrix W; standard polarimetric calibration |
| Cloude-Srinivasan eigenvalue decomposition | Classical | Cloude & Pottier, IEEE Trans. Geoscience 34, 498–518 (1996) | Physically valid Mueller matrix decomposition via eigenvalue filtering |
| Polar decomposition (Lu-Chipman) | Classical | Lu & Chipman, J. Opt. Soc. Am. A 13, 1106–1113 (1996) | Decomposes M into retardance, diattenuation, and depolarization components |
| TV-regularized Mueller imaging | Optimization | Aïnouz et al., Optics Letters 37, 1811–1813 (2012) | Spatially-regularized polarimetric inversion; reduces noise amplification |
| MuellerNet | Deep Learning | Dong et al., Optics Express 29, 23070 (2021) | CNN for direct Mueller matrix reconstruction from polarimetric images |
