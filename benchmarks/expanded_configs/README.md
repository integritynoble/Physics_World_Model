# PWM Expanded Benchmark Configs

> **168 modalities x 4 benchmarks (B1-B4) x all sub-cases = 53,484+ test instances**

## Overview

Each expanded config enumerates ALL system variants, image sizes, noise levels,
and mismatch levels for a single imaging modality. Together they form the complete
PWM benchmark test matrix.

## Benchmark Structure

### B1: Design (Prompt + original-spec -> Spec)
- Tests router/LLM ability to generate valid imaging system specifications
- Uses 11 typed primitives (Src, P, M, R, Pi, F, C, W, Sigma, S, D)
- 4 difficulty levels x 3 rounds = 12 prompts per variant
- Multi-round refinement tests iterative spec generation

### B2: Forward + Reconstruct (Spec -> Reconstruction + Feedback)
- Full combinatorial: variants x sizes x noise x mismatch
- Spec directly specifies imaging system (can build forward model)
- Metrics: PSNR, SSIM, SAM

### B3: System Identification (Dataset + Prompt -> Spec)
- Each case has a **true-spec** with exact parameter values
- Contestant only knows parameter ranges, not exact values
- Tests parameter estimation ability

### B4: Correct + Diagnose (Dataset + Spec -> Correction + Feedback)
- Includes **true-spec** for judging correction quality
- Tests mismatch correction + diagnostic feedback

## Data Source Priority

1. `WEB` - Published benchmark datasets from web
2. `EXP` - Real experimental datasets
3. `SYN-WEB` - Synthetic datasets from web (not self-created)
4. `GEN` - Generated by code

## Files

- `cassi_expanded.yaml` - Hand-crafted, 9 CASSI variants, 8,748 cases
- `ct_expanded.yaml` - Hand-crafted, 6 CT variants, 1,512 cases
- `*_expanded.yaml` - Auto-generated from variant registry + base configs

## Usage

```bash
# Enumerate all cases
python3 -m benchmarks.runners.enumerate_cases --summary

# Single modality detail
python3 -m benchmarks.runners.enumerate_cases --modality cassi --benchmark B2 --limit 20

# Generate missing expanded configs
python3 -m benchmarks.runners.generate_expanded_configs --all-configs
```
