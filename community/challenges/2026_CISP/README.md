# CISP 2026: Critical Assessment of Spectral/Spatial Imaging Prediction

The first annual CISP challenge for computational imaging reconstruction
and calibration.

## Overview

CISP evaluates the ability of reconstruction algorithms to recover images
from measurements made under **realistic model mismatch**. Unlike standard
benchmarks that test denoising or resolution, CISP tests whether algorithms
can handle the gap between assumed and actual physics.

## Scoring

All tracks use the PWM 4-scenario protocol:

- **Scenario I**: Solve with true operator (ideal upper bound)
- **Scenario II**: Solve with mismatched operator (naive baseline)
- **Scenario III**: Calibrate then solve (the test)
- **Scenario IV**: Oracle mask (diagnostics)

Primary metric: **rho** (recovery ratio) = (PSNR_III - PSNR_II) / (PSNR_I - PSNR_II)

Anti-Goodhart scoring: S_rank = 0.3 * S_retro + 0.7 * S_prospective

See `scoring/cisp_scorer.py` for implementation.

## Submission Format

Submissions are standard PWM RunBundles (v0.3.0):

```bash
# Generate your submission
pwm evaluate --modality cassi --solver my_solver --output submission/

# Validate before submitting
pwm contrib check my_solver

# Submit
pwm submit submission/runbundle_*.zip
```

## Rules

1. **One submission per team per track** (resubmission allowed until deadline)
2. **Solvers must pass isolation checks** (`pwm contrib check`)
3. **No access to ground truth** during reconstruction
4. **Compute budget enforced**: declared GPU-hours must be honest (2x = DQ)
5. **Open source required**: solver code must be published with submission
6. **RunBundle integrity**: SHA-256 hashes verified by stewards

See `governance/rules.md` for full rules and appeal process.
