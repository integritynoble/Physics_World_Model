# CISP 2026 Datasets

## Data Source

CISP 2026 uses **sealed-simulator data** generated by the PWM harness.
No real-world data is used in the first edition.

## Generation

```bash
# Generate data for a specific track
python generate_cisp_data.py --track correct --severity moderate --scenes 10 --seed 2026

# Generate all tracks
python generate_cisp_data.py --track all --severity moderate --scenes 10 --seed 2026
```

## Data Format

Each scene directory contains:

```
track_name/modality_name/scene_XXXX/
  x_gt.npy          # Ground truth scene (float32)
  y.npy             # Measurement with mismatch + noise (float32)
  metadata.json     # Scene parameters, mismatch values, provenance
```

Each track directory contains:

```
track_name/
  manifest.json     # SHA-256 hashes for all scenes, generation parameters
```

## Integrity

All data files are SHA-256 hashed in `manifest.json`. Participants must
verify hashes before evaluation:

```python
import hashlib, json, numpy as np

manifest = json.load(open("correct/manifest.json"))
for mod, info in manifest["modalities"].items():
    for scene in info["scenes"]:
        # Verify hash matches
        ...
```

## Sealed Simulator

The sealed simulator generates data using PWM's OperatorGraph compiler with
parameters that are NOT disclosed to participants. This prevents overfitting
to specific mismatch configurations.

Sealed parameters include:
- Exact mismatch values (within declared severity range)
- Random seed for scene generation
- Noise realization

Participants receive only `y.npy` (measurements) and the nominal operator
specification (via `pwm evaluate`). Ground truth `x_gt.npy` is held by
CISP stewards for scoring.

## Access

- **Sandbox data**: Available at registration (small, for development)
- **Sealed test data**: Released on 2026-08-15 (evaluation data)
- **Ground truth**: Released after submission deadline (2026-10-15)

## Dimensions

| Modality | Scene Shape | Measurement Shape | Spectral/Temporal Channels |
|----------|------------|-------------------|---------------------------|
| CASSI | 256x256x28 | 256x256 | 28 spectral |
| SPC | 64x64x28 | 64x64 | 28 spectral |
| CACTI | 256x256x8 | 256x256 | 8 temporal |
| Widefield | 256x256 | 256x256 | -- |
| MRI | 256x256 | k-space | -- |
| CT | 256x256 | sinogram | -- |
